Arquitectura

Diseño de sistemas distribuidos basados en microservicios y arquitecturas orientadas a eventos, construyendo plataformas escalables, resilientes y desacopladas para entornos de alta demanda.

Enfocado en comunicación asíncrona, gobierno de APIs y seguridad, incluyendo autenticación y autorización centralizada mediante Keycloak, así como optimización de rendimiento a nivel de base de datos.

Microservicios

Diseño basado en dominios y descomposición de servicios, implementando sistemas backend escalables con Node.js y Golang.

Eventos

Arquitectura orientada a eventos con Kafka para desacoplamiento, resiliencia y consistencia en sistemas distribuidos.

Seguridad

Seguridad desacoplada con Keycloak y Kong (JWT, OAuth2), usando plugins para control de acceso y protección de APIs, con prácticas seguras como bcrypt.

Performance

Optimización end-to-end: Angular Signals para eficiencia en renderizado, caching con Redis para reducir latencia y tuning de base de datos mediante planes de ejecución e indexación.

Observabilidad

Monitoreo y análisis de métricas con Grafana, junto con seguimiento de despliegues y trazabilidad mediante Argo CD en entornos Kubernetes.

Cloud & DevOps

Experiencia en despliegues con Docker y Kubernetes, incluyendo gestión de pods, ingress controllers para exposición de servicios, y participación en pipelines CI/CD con GitHub Actions, GitLab CI y Azure DevOps.
